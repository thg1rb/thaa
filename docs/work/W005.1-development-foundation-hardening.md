# W005.1 — Development Foundation Hardening

## Status

Done — merged into `develop` through PR #11 (merge commit
`f962af7b8e9763abf5a30f476f4a281ea6d6beec`).

## Objective

Harden the contributor and Agent development foundation before W006 by
establishing a vetted Project Skill set, explicit formatting/editor behavior,
coding standards, and a clear description of the existing Tauri repository
layout.

## Scope

- Discover, review, and install appropriate Project Skills.
- Document skill provenance, scope, limitations, and invocation guidance.
- Add explicit Prettier and EditorConfig rules without broad reformatting.
- Document coding standards and formatter ownership.
- Verify and document the actual root frontend plus `src-tauri/` layout.
- Run current application and documentation quality checks.

## Out of Scope

Shared domain models (W006), application or product functionality, dependency
changes, Cargo workspace introduction, project license selection, CI changes,
and release tooling.

## Requirements

Supports `NFR-007` (accessibility), `NFR-008` (maintainability), `NFR-009`
(cross-platform validation), `NFR-010` (dependency/supply-chain discipline),
and `PR-001`/`PR-002`/`PR-003` (local-first, macOS/Windows first-class, and
platform isolation) by making the development rules explicit. This work
implements no frozen functional requirement and does not change the baseline.

## Dependencies

W001–W005 are Done and integrated into `develop`. W006 — Shared Domain Models
remains the next product work item and is not started here.

## Design Notes

Preserve the established Tauri layout: frontend/tooling configuration at the
repository root, React source under `src/`, and the single Rust/Tauri Cargo
project under `src-tauri/`. Keep formatting scripts curated so frozen
requirements and vendored Project Skill contents are not rewritten. Rust stays
under `rustfmt`; ESLint remains focused on code quality.

Selected skills must be copied only to project scope and have their upstream
content hashes recorded in `skills-lock.json`. Where no Tauri-specific skill
passes the trust bar, official Tauri documentation and W003 remain authoritative.

## Security Considerations

Inspect skill instructions and supporting files before installation. Skills are
guidance with full agent permissions; do not run embedded scripts without
separate review. Do not install globally. Keep system-derived values untrusted,
do not add external services or dependencies, and preserve vendored skill
content/hashes.

## Platform Considerations

Keep EditorConfig and package scripts portable. Rust remains in the nested
Tauri project; Windows validation status must not be inferred from macOS checks.
