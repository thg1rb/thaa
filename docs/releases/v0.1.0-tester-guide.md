# Thaa v0.1.0 — selected tester guide (draft)

**Status:** Draft. No tester package is currently available.

## Install

Use only packages linked from the official GitHub Pre-release announced by the
project owner. The release assets are publicly downloadable. macOS testers
should use the signed and notarized Apple Silicon DMG on macOS 15 or later;
until one is available, macOS distribution is not ready. Windows testers
should use the unsigned Windows 11 x64 NSIS installer. No MSI is provided.

Windows may show “Windows protected your PC.” If Windows offers **More info →
Run anyway**, that is a per-app decision; continue only after verifying the
installer came from the official release and its hash matches
`SHA256SUMS.txt`. Smart App Control or managed-device policy may block the
installer entirely. Do not disable SmartScreen, Smart App Control, or other
Windows protections. Never substitute a local development build.

## First run

1. Launch Thaa normally; do not run it as administrator or root.
2. Confirm the Runtime Inspector shows local TCP listeners and available
   process details.
3. Search for a process name or exact port, then clear the query to restore all
   current listeners.
4. Refresh and confirm the active search remains applied to updated data.
5. Try copying or opening a local service URL if one is available.
6. Inspect a process before using Stop. Force Stop is stronger and may interrupt
   work; use it only when appropriate.

## Reporting issues

Record your OS version and architecture plus the steps and result. Remove
private process names, command lines, account names, and filesystem paths from
screenshots and bug reports. Use the [security policy](../../SECURITY.md) for
security issues; use [GitHub Issues](https://github.com/thg1rb/thaa/issues) for
ordinary feedback. Do not attach a crash dump or full process command line
unless the project owner has provided a secure collection method.
