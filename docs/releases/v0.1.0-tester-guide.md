# Thaa v0.1.0 — selected tester guide (draft)

**Status:** Draft. No tester package is currently available.

## Install

Use only packages linked from the official GitHub Pre-release announced by the
project owner. The release assets are publicly downloadable, but intended for
selected early testers. Both zero-budget packages are unsigned. macOS testers
should use the Apple Silicon DMG on macOS 15 or later; Windows testers should
use the Windows 11 x64 NSIS installer. No MSI is provided.

The macOS DMG is not Developer ID signed or Apple-notarized. macOS may warn or
block first launch. Only use a normal per-app approval option in System
Settings → Privacy & Security if the OS offers it and you trust the official
download after checking its checksum. If macOS offers no normal approval path,
stop and report the message. Never disable Gatekeeper or other macOS security
features globally.

Windows may show “Windows protected your PC.” If Windows offers **More info →
Run anyway**, continue only after confirming the official release and checking
the installer against `SHA256SUMS.txt`. Smart App Control or organization
policy may block installation entirely. If blocked, stop and report the
Windows edition/version and blocking behavior; do not disable SmartScreen,
Smart App Control, antivirus, or organization policy. Never substitute a local
development build.

## First run

1. Launch Thaa normally; do not run it as administrator or root.
2. Confirm the Runtime Inspector shows local TCP listeners and available
   process details.
3. Search for a process name or exact port, then clear the query to restore all
   current listeners.
4. Refresh and confirm the active search remains applied to updated data.
5. Try copying or opening a local service URL if one is available.
6. Inspect a process before using Stop. Force Stop is stronger and may interrupt
   work; use it only when appropriate.

## Reporting issues

For macOS, report the macOS version, Apple Silicon model category if known,
whether a first-launch warning appeared, install/launch outcome, tray and
Runtime Inspector behavior, quit/relaunch, and uninstall/reinstall outcome.
For Windows, report Windows edition/version and architecture, installer
launch, SmartScreen or Smart App Control behavior if shown, install/launch,
tray and Runtime Inspector behavior, quit/relaunch, and uninstall/reinstall.
For either OS, include steps and outcomes but remove private process names,
PIDs, command lines, account names, and filesystem paths. Use the [security
policy](../../SECURITY.md) for security issues; use [GitHub
Issues](https://github.com/thg1rb/thaa/issues) for ordinary feedback. Do not
attach a crash dump or full process command line unless the project owner has
provided a secure collection method.
