# Thaa v0.1.1 — Selected Tester Announcement (prepared, not sent)

Thaa `v0.1.1` is now available as an **Early Preview** for selected testers:
[download the official GitHub Pre-release](https://github.com/thg1rb/thaa/releases/tag/v0.1.1).
This patch fixes the macOS application-bundle signature defect in `v0.1.0`.

The macOS Apple Silicon package targets macOS 15 or later and remains ad-hoc
signed and not notarized, so macOS may show a first-launch verification
warning. Use only the normal per-app approval controls offered by macOS. The
Windows 11 x64 NSIS installer remains unsigned; SmartScreen may warn, and
Smart App Control or organization policy may block it. Do not disable system
security controls to install either package.

Please focus on install and first launch, tray access, Runtime Inspector,
listener discovery, Search, Refresh, Copy/Open, and quit/relaunch. Inspect
processes before using Stop or Force Stop, and test those actions only on safe,
disposable processes. Force Stop is destructive.

Report ordinary issues at [GitHub Issues](https://github.com/thg1rb/thaa/issues)
using the [v0.1.1 tester feedback template](v0.1.1-tester-feedback-template.md).
Include your OS version and architecture, and describe any security warning.
This message is prepared for the project owner and has not been sent.
