# Thaa v0.1.1

Know what's listening.

**Early Preview patch release for selected testers.** This release corrects
the invalid macOS app-bundle signature in v0.1.0 and adds strict validation of
the application bundle before and after DMG packaging.

The zero-budget distribution remains ad-hoc/unsigned on macOS and unsigned on
Windows. This patch does not add Developer ID signing, Apple notarization,
stapling, or Windows Authenticode. Normal operating-system security warnings
may still appear.

## Supported packages

- macOS 15 or later, Apple Silicon: `Thaa_0.1.1_aarch64.dmg`
- Windows 11 x64, NSIS: `Thaa_0.1.1_x64-setup.exe`

## Installation notes

The macOS app is not Developer ID signed or notarized. Verify the published
checksum, use only the normal per-app approval path offered by macOS if needed,
and do not disable Gatekeeper globally. The bundle-signature fix does not
guarantee that macOS will treat this unsigned, unnotarized app as trusted.

The Windows installer is unsigned. SmartScreen may warn, and Smart App Control
or managed policy may block installation. Do not weaken system security to
install it.

## Known limitations

- Windows Working Directory and Project Root metadata are unavailable through
  the current provider.
- Generic graceful Stop is not supported on Windows; Force Stop is available
  where supported and requires confirmation.
- Interactive Windows clean-machine validation remains deferred.

Please report installation, launch, runtime, or stability problems through
[GitHub Issues](https://github.com/thg1rb/thaa/issues). Inspect processes
before using Stop or Force Stop, and test process actions only with safe,
disposable processes.
