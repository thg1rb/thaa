# Thaa v0.1.1 macOS Candidate Retest

This retest is mandatory before publishing v0.1.1 because the published
v0.1.0 app bundle failed strict signature validation. Use only the exact
macOS DMG downloaded from the accepted GitHub Actions candidate run. Do not
substitute a local rebuild.

> **XProtect triage disposition:** The exact candidate and a minimal ad-hoc
> control both produced the same internal XProtect diagnostic on the tested
> GitHub-hosted macOS 15 and macOS 26 images. The same candidate/control did
> not produce it on local macOS 27. Hosted-runner logs showed SystemPolicy
> assessment/database errors, with no candidate file or rule identified.
> This is classified as an environment-specific diagnostic for those exact
> runner images, not as proof that all macOS environments are clear. The
> exact candidate is cleared to proceed to this user retest only. Publication
> remains blocked until the checksum, installed-app strict signature, and
> normal first-launch checks below pass. Do not remove quarantine or change
> system security settings.

## Verify and install

1. Record the candidate source SHA, workflow run, and exact DMG filename.
2. From the download directory, verify the published candidate checksum:

   ```bash
   shasum -a 256 Thaa_0.1.1_aarch64.dmg
   ```

   Compare the result with the candidate's `SHA256SUMS.txt`.

3. Open the DMG and copy `Thaa.app` into `/Applications` using Finder.
4. Before launching, run:

   ```bash
   codesign --verify --deep --strict --verbose=4 /Applications/Thaa.app
   ```

   **Expected:** exit code `0`, with no resource-seal or Info.plist coverage
   errors. If this fails, stop and report the output; do not remove quarantine
   or bypass the signature failure.

5. Attempt first launch through the normal macOS UI. Record the actual
   Gatekeeper behavior. The app remains ad-hoc signed and not notarized, so a
   normal per-app security approval may still be required. Do not disable
   Gatekeeper or other system security globally.
6. If launch is acceptable, check tray access, Runtime Inspector, listener
   discovery, Search, Refresh, process metadata, Copy/Open, and safe process
   actions. Quit, relaunch, uninstall, and reinstall where practical.
