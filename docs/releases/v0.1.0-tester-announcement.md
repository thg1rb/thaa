# v0.1.0 Selected Tester Message — Draft

Thaa v0.1.0 is an early pre-release for selected testers. It helps you see
which local processes own listening ports, search by process name or exact
port, inspect available process/project context, and refresh the current view.

Please try installation and first launch, tray access, listener discovery,
Search, Refresh, copy/open actions, quit/relaunch, and uninstall. Report
ordinary bugs at [GitHub Issues](https://github.com/thg1rb/thaa/issues), with
your OS version and reproduction steps. Remove private process names, PIDs,
command lines, and filesystem paths from reports. Use the private [security
reporting policy](../../SECURITY.md) for security issues.

The first macOS package targets Apple Silicon on macOS 15 or later and must be
signed and notarized before distribution. The Windows 11 x64 NSIS installer is
unsigned; Windows may warn or block it, and Smart App Control or managed-device
policy may prevent launch. Do not disable OS security protections. Windows
Working Directory/Project Root and generic graceful Stop are unavailable.

Inspect a process before acting. Stop is platform-dependent; Force Stop is a
stronger, destructive action and requires confirmation. Do not use either on a
process unless you understand its purpose.
