# v0.1.0 Selected Tester Message — Draft

Thaa v0.1.0 is an early pre-release for selected testers. It helps you see
which local processes own listening ports, search by process name or exact
port, inspect available process/project context, and refresh the current view.

Please try installation and first launch, tray access, listener discovery,
Search, Refresh, copy/open actions, quit/relaunch, and uninstall. Report
ordinary bugs at [GitHub Issues](https://github.com/thg1rb/thaa/issues), with
your OS version and reproduction steps. Remove private process names, PIDs,
command lines, and filesystem paths from reports. Use the private [security
reporting policy](../../SECURITY.md) for security issues.

Both zero-budget packages are unsigned. The Apple Silicon macOS 15+ DMG is not
Developer ID signed or Apple-notarized, so macOS may warn or block first launch.
The Windows 11 x64 NSIS installer is unsigned; SmartScreen may warn, and Smart
App Control or organization policy may prevent installation. Download only
from the official GitHub Release and check the published checksum. Use only a
normal per-app OS approval flow if offered. If the OS blocks the build without
a normal approval option, stop and report the message. Do not disable OS
security protections.

Windows feedback should include Windows edition/version, architecture,
installer/SmartScreen behavior, install and first-launch outcome, tray,
Runtime Inspector, quit/relaunch, and uninstall/reinstall. macOS feedback
should include macOS version, Apple Silicon model category if known,
first-launch warning behavior, install/launch, tray, Runtime Inspector,
quit/relaunch, and uninstall/reinstall. Avoid attaching private paths or
process details. Windows Working Directory/Project Root and generic graceful
Stop are unavailable.

Inspect a process before acting. Stop is platform-dependent; Force Stop is a
stronger, destructive action and requires confirmation. Do not use either on a
process unless you understand its purpose.
