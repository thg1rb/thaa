# v0.1.0 Selected Tester Message — Draft (not sent)

Thaa `v0.1.0` is available as an **Early Preview** for selected testers. It
helps you see which local processes own listening ports, search by process name
or exact port, inspect available process/project context, and refresh the
current view. This is not a stable or production-ready release.

Download only from the official [Thaa GitHub Pre-release](https://github.com/thg1rb/thaa/releases)
after publication. Verify the SHA-256 values shown on the release page or in
`SHA256SUMS.txt`:

```text
Thaa_0.1.0_aarch64.dmg
4365f2a0d91ef5865f3aaad953fdce004c80ed8425272af9ad2c5af8fb438297

Thaa_0.1.0_x64-setup.exe
f2503274b4a6d432b27c3203029f37126791ccf851f7900d6f092c45a9944073
```

Both packages are unsigned. The Apple Silicon macOS 15+ DMG is not Developer
ID signed or Apple-notarized; macOS may warn or block first launch. Use only a
normal per-app approval flow offered by macOS. The Windows 11 x64 NSIS
installer is unsigned; SmartScreen may warn, and Smart App Control or
organization policy may prevent installation. Do not disable system security
controls; if your OS blocks installation, stop and report the environment and
message.

For a **10–20 minute core test**, please try installation, first launch, tray,
Runtime Inspector, listener discovery, Search, Refresh, Copy/Open, and
quit/relaunch. Use a safe disposable process for Stop/Force Stop; these actions
can terminate running software, and Force Stop is destructive. Optional
extended testing takes about 30–60 minutes. An optional power-tester stability
session is approximately eight hours; continuous interaction is not needed.

Report ordinary issues at [GitHub Issues](https://github.com/thg1rb/thaa/issues)
using the [tester feedback template](v0.1.0-tester-feedback-template.md).
Include OS version and architecture, and describe any security warning. Remove
private process names, PIDs, command lines, account names, and filesystem
paths. Use [SECURITY.md](../../SECURITY.md) for security issues.

Windows Working Directory and Project Root are unavailable in the current
provider, and generic graceful Stop is unsupported. Interactive Windows
clean-machine validation has not yet been performed. See the [tester guide](v0.1.0-tester-guide.md)
for installation details and known limitations.
