# Thaa v0.1.0

Know what's listening.

> **Early Preview for selected testers.** Thaa `v0.1.0` is an early
> pre-release. It is not stable, production-ready, warning-free, or broadly
> validated on every environment.

> **Known macOS issue:** The published v0.1.0 DMG contains an invalid
> application-bundle signature and may show “Thaa is damaged and can’t be
> opened.” Do not install this package or bypass macOS security. A corrected
> macOS patch release is in preparation. Windows is not currently known to be
> affected.

Thaa helps developers find local listening ports, identify their owning
processes, inspect available process/project context, and take supported
actions from a native desktop interface.

## What's included

- Discover local listening TCP ports and their process owners where the OS
  permits inspection.
- View process name, PID, executable path, Working Directory, and best-effort
  Project Root metadata when available.
- Search by case-insensitive process-name substring or exact numeric port.
- Refresh the listener view while keeping the current search.
- Copy a service URL, port, or PID; open a validated local service URL.
- Request supported graceful Stop actions or confirm a separate Force Stop
  action. A request does not guarantee that a process exited; a later scan
  verifies the outcome.
- Use the native macOS menu bar or Windows system tray entry point.

## Installation notes

### macOS

The Apple Silicon package targets macOS 15 or later. It is not Developer ID
signed and is not notarized by Apple. macOS may warn or block first launch.
After obtaining the DMG from the official release, compare its checksum with
`SHA256SUMS.txt`. If you trust the verified artifact, use only a normal
per-application approval flow offered by macOS. Do not disable Gatekeeper or
other security controls globally. If no normal approval path is offered, stop
and report the message.

### Windows

The Windows 11 x64 package is an unsigned NSIS installer. Microsoft Defender
SmartScreen may warn. Smart App Control or organization-managed policy may
block installation. Do not disable SmartScreen, antivirus, Smart App Control,
or organization policy. If blocked, stop and report the environment and
message.

## Known limitations

- Windows does not currently expose Working Directory, so Project Root is
  unavailable there.
- Generic graceful Stop is not supported for arbitrary discovered processes
  on Windows. Force Stop is available where supported and requires
  confirmation.
- Interactive Windows clean-machine validation has not been performed by the
  project; selected testers are invited to provide that evidence.
- Linux is not a release target.

## Testing and feedback

Please try installation, first launch, tray access, Runtime Inspector,
listener discovery, Search, Refresh, and available Copy/Open actions. Use a
safe disposable process if testing Stop or Force Stop. These controls can
terminate software; Force Stop is destructive. Do not target system-critical
processes or applications with unsaved work.

Report ordinary issues at [GitHub Issues](https://github.com/thg1rb/thaa/issues).
For security issues, follow [SECURITY.md](https://github.com/thg1rb/thaa/blob/main/SECURITY.md).
Remove private process names, PIDs, command lines, account names, and
filesystem paths from reports. See the [selected tester guide](https://github.com/thg1rb/thaa/blob/develop/docs/releases/v0.1.0-tester-guide.md)
and [feedback template](https://github.com/thg1rb/thaa/blob/develop/docs/releases/v0.1.0-tester-feedback-template.md).
