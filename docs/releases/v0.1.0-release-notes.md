# Thaa v0.1.0

<!-- Draft release notes for the selected-tester Pre-release; not published. -->

Thaa is a local runtime and port inspector for developers. The first release
focuses on helping you identify which process owns a listening TCP port, inspect
available process/project context, and take supported actions from a native
desktop interface.

## Included

- Discover local listening TCP ports and their process owners where the OS
  permits inspection.
- View process name, PID, executable path, Working Directory, and best-effort
  Project Root metadata when available.
- Search by case-insensitive process-name substring or exact numeric port.
- Refresh the current listener snapshot without losing the active search.
- Copy a service URL, port, or PID; open a validated local service URL.
- Request supported graceful Stop actions or confirm a separate Force Stop
  action. A request is not confirmation that the process exited; a later scan
  verifies the outcome.
- Use the native macOS menu bar or Windows system tray entry point.

## Platform notes

- **Early Preview notice:** Thaa `v0.1.0` is an early pre-release for selected
  testers. It is not production-ready, warning-free, or broadly validated on
  every supported environment.
- macOS: first package targets Apple Silicon and macOS 15 or later. The planned
  `Thaa_0.1.0_aarch64.dmg` is not Developer ID signed and is not notarized by
  Apple. macOS may warn or block first launch. Download only from the official
  GitHub Release and compare the DMG hash with `SHA256SUMS.txt`. Use only the
  normal per-app approval flow offered by macOS; never disable Gatekeeper or
  system security globally. If no normal approval path is offered, stop and
  report the message.
- Windows: first package targets Windows 11 x64 with the unsigned NSIS
  installer `Thaa_0.1.0_x64-setup.exe`. No MSI is planned. Windows may show
  “Windows protected your PC”; if available, the normal per-app continuation is
  **More info → Run anyway**. Continue only after confirming the official
  source and comparing the installer hash with `SHA256SUMS.txt`. Smart App
  Control or organization policy may block unsigned installers entirely. If
  blocked, stop and report the environment; do not disable security protections.
- `SHA256SUMS.txt` will contain hashes for the exact published artifacts.
- Windows currently does not expose Working Directory or Project Root in the
  process provider. Generic graceful Stop is not supported for arbitrary
  discovered processes.
- Linux is not a release target.

## Before testing

Install only packages linked from the official GitHub Pre-release after they
have been built and validated. Both zero-budget packages are unsigned. Verify
the source and checksum before deciding whether to continue through a normal
per-app operating-system approval flow. Do not install locally built
candidates. See the [README](../../README.md) for installation steps and
current limitations. Report issues through the project's private security
process for security concerns, or GitHub Issues for ordinary bugs; remove
private process names, paths, and command data from reports.
