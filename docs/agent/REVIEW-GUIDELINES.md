# Review Guidelines

The review Sub-agent is read-only. It checks acceptance criteria and requirement traceability, Rust/frontend boundaries, macOS/Windows behavior, test quality, error and permission handling, stale process safety, privacy-sensitive data, dependency/workflow changes, and documentation consistency.

Findings use the prompt's severity levels: Critical, High, Medium, Low, Suggestion. State the affected file/behavior, impact, and evidence. Do not inflate severity or invent findings. The main Agent owns all fixes and validation.
