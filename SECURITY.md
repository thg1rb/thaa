# Security Policy

## Reporting a vulnerability

Please report suspected security vulnerabilities through GitHub's **Report a vulnerability** feature for this repository. This creates a private report for maintainers. Do not disclose a suspected vulnerability in a public issue, discussion, or pull request before maintainers have had a reasonable opportunity to assess it.

Include the affected component, impact, reproducible steps, and any relevant version or commit information. Do not include real credentials or unrelated private process data. The project does not promise a response or remediation timeline; maintainers will coordinate privately through the report where possible.

This repository's private vulnerability reporting channel is enabled. The engineering security controls and threat model are documented in [docs/security/SECURITY.md](docs/security/SECURITY.md) and [docs/security/THREAT-MODEL.md](docs/security/THREAT-MODEL.md).
